# Unity Editor setup — Jack and the Unreliable Narrator

## Implemented automatically in the repository

Gameplay and typed narrator modules are in `Assets/Scripts/Jack/`. The builder is `Assets/Editor/JackDemoBuilder.cs`. It uses all four supplied backgrounds across five beats, creates the Canvas and reference wiring, configures the 29 sprites as Single / 100 PPU / bilinear, and creates an unlit URP 2D material. Your existing URP assets, package versions, SampleScene, and plugin remain in place. Unity owns and retains the art metadata GUIDs; importer changes happen through Unity APIs when you run the builder.

Pixelify Sans and its OFL license are included in `Assets/Fonts/PixelifySans/`; the builder generates its TMP heading asset. The only narrator identification is the text heading `Narrator`. All actor objects are created at runtime under `__JackDemo/LevelActors`, so an empty LevelActors root outside Play mode is expected.

## MANUAL ACTIONS REQUIRED FROM ME

1. **Open the existing project in Unity 6000.6.7f1.** Save your current scene. Let Unity finish importing and compiling. Open **Window > General > Console** and fix any red errors before continuing. No package upgrades or renderer replacements are needed. Keep **Edit > Project Settings > Player > Other Settings > Active Input Handling** on **Input System Package (New)** (the current setting), or Both.
2. **Verify supplied art.** All 29 expected PNGs were found during implementation. Keep the filenames and case unchanged. The exact manifest is `JackDemoBuilder.ArtPaths`. In particular the backgrounds must be `01_Merchant_Village_Post_Beanstalk.png`, `02_Beanstalk_Climbing.png`, `03_Giant_Castle.png`, and `04_NightEscape.png` under `Assets/Art/Backgrounds/`. The builder logs every missing path and writes its latest audit at the bottom of this document. Restore missing assets before rerunning; do not rename unrelated art.
3. **Import TMP Essentials if absent.** Choose **Window > TextMeshPro > Import TMP Essential Resources**, then **Import**. Wait for completion. The required readable fallback is `Assets/TextMesh Pro/Resources/Fonts & Materials/LiberationSans SDF.asset`. If the menu is unavailable, verify the existing Unity UI package is installed in **Window > Package Management > Package Manager**. Do not install a second TMP package.
4. **Generate the scene.** Choose **Tools > Jack > Create or Refresh Demo Scene**. It saves `Assets/Scenes/JackGame.unity`, selects GameManager, and adds the scene to the shared build list. Accept Unity's save-current-scene dialog if you have unsaved work. This command rebuilds the generated `__JackDemo` hierarchy; put personal scene additions outside that root. It retains NarratorClient's API URL and mock toggle when refreshed. Other scenes and unrelated roots are preserved. Do not run the builder during Play mode.
5. **Check the font and parchment.** Expand `__JackDemo > Canvas > Parchment dialogue > Narrator`. The TMP font should be `PixelifySans SDF` and the text should read `Narrator`. Paragraphs use Liberation Sans. If Pixelify generation fails, the builder assigns the readable TMP fallback and logs a warning. To replace it manually: select `Assets/Fonts/PixelifySans/PixelifySans.ttf`, choose **Assets > Create > TextMeshPro > Font Asset**, and drag the resulting asset into the heading's **Font Asset** field and `Assets/JackGenerated/ArtCatalog.asset > Heading Font`. If the TTF is missing, obtain it with `OFL.txt` from https://github.com/google/fonts/tree/main/ofl/pixelifysans and place it at the same project path. Rebuild after removing only the failed generated font asset if needed. Parchment borders are set to 36 px on all sides for the dialogue and 22 px for input/buttons, based on inspection of the supplied images; no sheet slicing is used.
6. **Run the offline demo.** Select `__JackDemo > GameManager`; in **Narrator Client**, leave **Use Mock Narrator** checked. Click **Play**. The opening line must appear, with Jack, merchant, cow, stall, and beans visible. Use **A/D** or **left/right arrows** to walk; approach an actor and press **E**, or click/tap it to fill a contextual request. Edit the input and press **Enter** or **Submit**. Movement stops while the text field has focus. Click the world or press Escape to leave input focus. Follow `Documentation/DEMO_SCRIPT.md` to victory. Click **Next chapter** only when the objective is satisfied, and **Escape!** on the final beat. **Restart** resets inventory, history, spawned objects, turn count, and pending requests.
7. **Check layout and interactions.** In the **Game** view, use **16:9**, then **4:3**, then **Free Aspect** and a narrow window. Check that the heading, narration, input, inventory, next button, and actor labels remain readable. Drag or scroll the narration area if a long response exceeds the parchment viewport. Canvas Scaler uses **1600 x 900**, **Match 0.5**; camera fitting reads actual 1672 x 941 background bounds. Character/prop sizing is independent of source PNG dimensions. Verify the idle/two-frame walking loop, flip direction, and climb sprite when leaving beat 3. This is a story puzzle with bounded walking, not a physics platformer.
8. **Run the automated Unity checks.** Open **Window > General > Test Runner** (some layouts show **Window > Test Runner**), select **EditMode**, find **Jack.Tests**, and run both tests. These regenerate JackGame and enter/exit Play mode to check the complete offline win path, idempotent setup, missing-ID rejection, double submission, and restart cancellation. Save unrelated work first. Tests require TMP Essentials. Also inspect Console for zero compile errors and no missing references.
9. **For live narration, obtain a private server API key.** Create a Gemini API key at https://aistudio.google.com/apikey. Never paste it into a Unity Inspector, C# file, screenshot, chat, or Web build. See `Documentation/DEPLOYMENT.md` for private `.env` and Netlify runtime-variable setup, model availability, and quota controls. Offline play needs no account, key, or backend.
10. **Run the local backend.** Install Node **22 LTS or newer supported LTS**, open a terminal at the project root, and run `npm install`, `cp .env.example .env`, and `npm run dev` (Netlify dev, port **8888**). Initially keep `MOCK_NARRATOR=true` and `ENABLE_LIVE_NARRATOR=false`. For live testing, privately edit `.env` with `GEMINI_API_KEY`, set `MOCK_NARRATOR=false`, `ENABLE_LIVE_NARRATOR=true`, and restart the server. Use `npm run models` to list accessible models. `npm run serve:mock` is an alternative localhost API runner using the same handler and `.env`; do not run both servers on port 8888 simultaneously.
11. **Configure Editor live mode.** Stop Play. Select GameManager > **Narrator Client**: uncheck **Use Mock Narrator**, set **Api Url** to **`http://localhost:8888/api/narrate`**, and keep **Timeout Seconds = 15**. Save. Play and submit a free-form request. Status must say **Live narrator** for a successful real response; **Offline fallback** means the deterministic understudy handled it. Stop the backend while playing and verify a later request still works via the fallback. No other inspector references need manual assignment.
12. **Prepare a Web build if needed.** In **Unity Hub > Installs > 6000.6.7f1 > gear / three-dot menu > Add modules**, install **Web Build Support** if absent. In Unity choose **File > Build Profiles > Add Build Profile > Web**, then **Switch Profile**. In the profile's **Scene List**, enable only `Assets/Scenes/JackGame.unity` for this demo, or place it first and disable SampleScene. The builder deliberately does not remove your other build entries.
13. **Set production client and build options.** Stop Play, select GameManager > Narrator Client, set **Api Url = `/api/narrate`**, **Use Mock Narrator = false**, and save the scene. For a fully offline judging build leave mock checked instead. Under **Edit > Project Settings > Player > Web > Publishing Settings**, set **Compression Format = Disabled**, **Decompression Fallback = off**, **Name Files As Hashes = on** if offered, and **Data Caching = on**. Use the **Default** Web template, not Minimal, and leave Web threading disabled for this MVP. Set **Run In Background = on** under Resolution and Presentation if desired. Choose **Build** and select the project's `web-build/` directory; verify it directly contains `index.html`, `Build/`, and `TemplateData/` (no extra enclosing build folder).
14. **Deploy and browser-test if needed.** Follow `Documentation/DEPLOYMENT.md` to configure a Netlify site, private runtime environment, and deploy the static build plus function. Test the published HTTPS URL in a desktop browser and a narrow viewport. Confirm the `/api/narrate` response, four backgrounds/five beats, bean and goose inventory changes, ladder fall/stabilization, victory, and restart. Check developer tools for failed `.wasm`, `.data`, `.js` or API requests. A local `file://` launch is not a valid WebGL test. Real Gemini calls and a deployed browser build require your credentials/build and are not implied by code checks.

## Troubleshooting

- **Pink sprites:** verify the existing UniversalRP asset remains assigned in Graphics and Quality settings. The generated PaperUnlit material should use `Universal Render Pipeline/2D/Sprite-Unlit-Default`. No Global Light is necessary for that material; do not add one just to compensate for missing shader references.
- **No UI clicks:** ensure the generated EventSystem has Input System UI Input Module and its default actions. Do not add a second EventSystem.
- **API error or rate limit:** status reports fallback; keep playing. Verify `.env`, live opt-in, model access, and quotas privately. There are at most two 5-second API attempts and a 15-second Unity timeout.
- **Unknown generated object:** supported `generic` objects intentionally render a labeled cardboard square. Unsupported IDs/actions are refused, with failure narration instead of false claims.
- **Builder errors on missing TMP:** finish importing Essentials, then run the builder again. It stops before overwriting scene content when required art or TMP dependencies are absent.
- **Your custom scene edits disappear on refresh:** edit outside `__JackDemo`, or put enduring layout changes into the builder. The generated root is owned by the setup script.
